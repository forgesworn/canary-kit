# Canary — our words

Open [canary-local.html](../canary-local.html) directly in a browser. No server,
installation, account or connection is needed to use the built file.

1. One person chooses **Make a pair**.
2. Exchange the 12 setup words in person or through an independently trusted
   route. The other person chooses **I have setup words**. Alternatively, save
   and privately transfer **their private copy**. Both sides check the same pair
   reference. Use a different pair for every person.
3. Each person saves **my private copy** for next time. Open that file to resume.
4. On a call, say **You say**, then listen for **They should say**. Both phrases
   change on each UTC 30-second boundary. Wait at changeover if necessary.
5. Agree beforehand what the separate **My private signal** means and what the
   listener should do. The listener can enter either phrase under **Check what
   they said**. The tool sends no alerts.

The saved HTML files and setup words contain the **unencrypted shared secret**.
Treat them as passwords. A clean copy of the tool plus the 12 setup words avoids
accepting executable HTML from another person. Use new setup words generated by
this tool; never import a wallet recovery phrase. Closing a session does not
delete saved files, browser artefacts, clipboard history or the source file's
embedded secret. Reopening a saved private file restores its pair.

## Existing components reused

- `src/token.ts`: `deriveToken` and `deriveDuressToken`, with their existing
  identity labels, domain separation, word encoding and collision avoidance.
- Locked `spoken-token@2.1.0`: HMAC-SHA256, spoken en-v1 words, timing-safe
  comparison and crypto utilities. The adjacent `spoken-token` checkout is
  currently 2.1.1; this build follows this repository's unchanged lock file.
- Existing `@scure/bip39`: new 128-bit secrets encoded as 12 checksummed setup
  words. These are not the short-lived spoken words.
- Existing Vite and `vite-plugin-singlefile`: one bundled file. The build adds
  exact script/style CSP hashes, blocks connections and includes MIT notices.

This is an additional small entry point, separate from the `app/` demo. It does
not import Nostr, accounts, profile lookups, relays, maps, beacons, synchronisation
or location features. Existing library protocols and the larger app are unchanged.
WASM is not used; no cryptographic primitive has been reimplemented here.

## Practical security limits

These are time-counter tokens using the existing CANARY/SPOKEN protocol, not
interoperable RFC 6238 authenticator enrolments. The two fixed sides use different
labels under `canary:local-pair:v1`; both holders of the secret can derive both
sides. This is evidence of shared-secret knowledge, not a certificate of identity,
a record of a meeting, or proof that a person is safe.

Each spoken phrase has two words (22 bits). Manual comparison uses the currently
displayed words. The optional checker accepts the current interval and one on
either side: three candidate normal phrases, approximately 3 / 4,194,304 guessing
probability per random attempt. A token is accepted over a 90-second span of
verifier times. There is no consumed-token ledger or rate limiter. A live relay
can defeat a check; repeated guesses accumulate risk. Old offline copies cannot
be revoked remotely. If a setup secret is exposed, create and exchange a new pair.

Duress collision avoidance uses the library's ±2-tolerance normal-token window
with both side labels supplied. The checker prioritises a duress match. This
supports a human plan; it does not guarantee concealment, prevent a coercer
forcing the normal words, or provide emergency assistance. Avoid screen sharing
and displaying the private signal to someone who might coerce you.

Desktop Chromium file opening and a narrow mobile viewport have been checked.
Physical Android/GrapheneOS and iPhone file opening have not been accepted. Mobile
file managers sometimes preview HTML rather than open an executing browser tab;
do not describe this as a tested phone delivery route yet. The local interface,
export pipeline and its application protocol have not had an independent audit.

## Build and check

```sh
npm ci --no-audit --no-fund
npm run build:local
npm test -- --maxWorkers=2
npm run typecheck
npm run typecheck:local
npm run test:local
```

The browser check normally uses Playwright's installed Chromium. To reuse an
existing compatible executable instead of downloading another browser, set
`CANARY_CHROMIUM_EXECUTABLE` to its path. `CANARY_BROWSER=webkit` selects WebKit
when installed. The check cleans its downloaded private test files and closes
its browser. It runs without a test server.
