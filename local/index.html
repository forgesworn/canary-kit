Privacy & limitations

This file runs on your device. It makes no network requests and has no accounts, analytics, cookies, location access, camera access or automatic alerts. It does not remember a pair between sessions unless you explicitly save a private copy. Your browser, extensions and anyone with access to your files may still see secrets.

Exchange setup secrets only with someone you have met, or through an independently trusted channel. A familiar voice or video alone can be faked. Use a separate pair for each person. If a secret file or setup words are exposed, create a new pair and exchange it again; old offline copies cannot be revoked remotely.

The site cannot certify who you met, whether someone is safe, or whether they are being coerced. Anyone with the shared secret can derive either side’s words. Duress needs an agreed human response and offers no emergency service. This version has local checks; it has not had an independent security audit.

A future hosted download would expose ordinary connection data to that host. Hosting is not part of this local file.
